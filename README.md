# File-Organizer
This is my first big and public project, it's simply a file organizer that organize some certain types of files and it creates files to put the organized files in.
The code is made in python
You can put in the local of the file you want to organize, and when you start the operation it will appear a small menu where you can press 1 to organize the files, press 2 to redo the last change and press 3 to exit the operation
